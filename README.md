# PUBH-1142: Introduction to Health Data Science

Homework notebooks from PUBH 1142 at the George Washington University Milken Institute School of Public Health (Spring 2025). Written as coursework, so they answer the assignment prompts rather than being polished analyses.

| Notebook | Topic |
|---|---|
| `Chapter_3.ipynb` | Ethics and privacy: a health-data misuse case, a breach case, and an algorithmic-bias case |
| `Chapter_4.ipynb` | Spreadsheets vs. databases, REDCap, quiz answers |
| `Chapter6.ipynb` | Python basics |
| `Chapter9_HW.ipynb` | Exploratory data analysis: frequencies, contingency tables |
| `Chapter10.ipynb` | Data visualization with seaborn |
| `Chapter11Distributions_Quiz.ipynb` | Probability distributions (fixed random seed 12) |
| `Chapter12HW.ipynb` | Multiple linear regression with statsmodels (F-statistic, R², p-value) |

## Running

The notebooks need Python 3 with `numpy`, `pandas`, `scipy`, `statsmodels`, `seaborn`, `matplotlib` and `plotly`. Some load public datasets over HTTP at run time, so they need internet access. There is no pinned environment, and I have not re-run every notebook from a clean setup.
